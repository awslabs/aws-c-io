# Test Resources

## generateCerts.sh

Regenerates all test certificates used by unit tests (TLS connections between localhost server and client). Run this
script when certificates expire.

Generated files include RSA/EC self-signed certs, a CA-signed server cert chain, mTLS root CAs with server/device certs,
an untrusted server CA, and the macOS trust settings plist for `mtls_server_root_ca`. See the script header for the full list.

The PKCS#12 bundles (`*.p12`) are exported with SHA1/3DES encryption (`-keypbe PBE-SHA1-3DES -certpbe PBE-SHA1-3DES
-macalg sha1`) rather than OpenSSL 3.x's modern AES-256/PBES2 defaults, which macOS's Security Framework
(`SecPKCS12Import`) cannot parse.

Some certificates in this folder are intentionally *not* regenerated by the script (`testparse*.crt`, `testcert*.pem`,
`ecc-cert.pem`/`ecc-key.pem`, and `DigiCertGlobalRootCA.crt.pem`); see the script header for details.

### Automated renewal

The `.github/workflows/cert-renewal.yml` workflow runs `generateCerts.sh` on a monthly schedule (and on manual
dispatch). It checks the expiration of the generated certificates and, when the earliest one is within 30 days of
expiring, regenerates the full set and opens a pull request with the changes. Certificates are generated with an
824-day lifetime to stay under the 825-day cap Apple platforms enforce on TLS server certificate lifetimes.

## import_custom_cert_to_keychain.sh

macOS-only script used in CI to set up a temporary keychain with test certificates for keychain-related tests.
It creates a keychain, imports a trusted and an untrusted CA certificate, and configures trust settings
so that tests can verify correct behavior for both trusted and untrusted certificates.
